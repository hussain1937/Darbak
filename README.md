# 🚚 Darbak - Smart Logistics & Freight Bidding App

> A comprehensive mobile platform designed to revolutionize freight and logistics services through a smart bidding system.

**Darbak** is a senior graduation project developed by a team of Computer Science students at Umm Al-Qura University and showcased at the **Career and Innovation Exhibition**. The application bridges the gap between clients needing shipping services and logistics providers through a dynamic bidding environment.

## ✨ Key Features
- **Smart Bidding System:** Allows shipping companies and freelance drivers to place competitive bids on user shipment requests.
- **Dual-Role Interface:** Dedicated UI/UX for both standard clients and service providers.
- **Order Management:** Clients can create shipment requests, review incoming bids, and select the most suitable offer.

## 🛠️ System Architecture
The project was engineered using a robust full-stack architecture:
- **Frontend:** Flutter, Dart
- **Backend:** Node.js, RESTful APIs
- **Database:** MySQL (Relational database with comprehensive ER diagrams)

## 🚀 How to Run
1. Clone the repository: `git clone https://github.com/hussain1937/Darbak.git`
2. Configure the Node.js backend environment variables and import the MySQL database schema.
3. Run `flutter pub get` followed by `flutter run`.
